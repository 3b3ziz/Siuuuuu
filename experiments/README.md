# Experiments

One folder per person: `experiments/<your-name>/`. Your scratch space for trying ideas. Commit as often as you like, and only edit your own folder, so we never get merge conflicts.

- Reuse the shared code in `prep/` (`from sticky import sticky_labels`, etc.) instead of copying it.
- Put outputs (CSVs, scores) in `data/`, which git ignores, not here.
- When something beats the current best on the practice match, add a row to the results table in `docs/notes.md` and tell the team. If it becomes the new best, move it into `prep/`.
